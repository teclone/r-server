# Introduction to R-Server

R-Server is a powerful NodeJS web server optimized for both development and production needs. It provides:

- Built-in routing engine
- Request body parser
- Static file streaming with range request support
- File upload processing
- Middleware support
- Request-response profiler
- Exception handling
- Error logging
- HTTPS and HTTP/2 support

This documentation will guide you through setting up and using R-Server effectively.
